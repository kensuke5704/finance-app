# 現行機能一覧

この文書は、現在の `app/page.tsx` を基準にしたFinanceの機能一覧です。実装を変更するときは、保存形式と次の動作を維持します。

## アカウントと保存

- K・Mの2アカウントを切り替え、それぞれの資産・年利・予算を分離して管理する。
- 端末内では `finance.monthly-assets.v1` に自動保存する。
- Googleログイン済みかつ許可済みのメールアドレスでは、Firestoreの共有ドキュメントへ同期する。
- JSONバックアップは2アカウントをまとめて保存・復元する。旧形式の単一アカウントデータも読み込める。

## 資産

- 月ごとの資産額を入力し、入力月の範囲を積み上げグラフで表示する。
- 資産項目は追加・名称変更・削除・ドラッグ操作による並べ替えができる。
- S・L・LLでグラフの横軸期間を切り替える。入力がない月は実績の表示範囲に含めない。
- 年利と予算を使った予測を破線で表示し、予測残高が負になる場合は警告する。
- 金額の表示・非表示は端末ごとの設定として保持する。

## 予算

- 「予算」と「その他」に、単月・複数月・定期の予算を登録する。
- 予算には収入、支出、資産ごとの投資額、メモ、グループを設定できる。
- 開始月順・降順の表示、複製、削除を行える。
- M→K・K→Mグループは削除できず、収入と支出だけを相手アカウントへ反転同期する。

## 設定とデータ管理

- 資産ごとの年利を設定し、月利は年利から内部計算する。
- バックアップファイルの保存・復元を行う。
- PWAとして起動でき、Service Workerの更新時に新しい版を読み込む。

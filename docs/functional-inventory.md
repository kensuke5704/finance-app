# 現行機能の保持一覧

UIをゼロベースで再構成する際も、以下の機能・計算・保存形式は維持する。

## アカウントとデータ保全

- 1人目と2人目をロゴ操作で切り替える。データは完全に分離する。
- 1人目の既存データは変更しない。2人目は初期値0円で開始する。
- 変更内容は端末へ自動保存し、保存中・保存済み・保存エラーを表示する。
- 2人分を一つのJSONバックアップとして、共有・ダウンロード・復元できる。
- 旧形式の単一アカウントバックアップも、現在選択中のアカウントへ復元できる。

## 家計・ホーム

- 月ごとの実績入力: 現金収入、投資収入、贈与、現金支出、PayPay支出、カード支出、投資信託、アクティブ、FX。
- 月次予算と実績の比較、現金予測、月次の登録・削除。
- 現金・資産合計・通算損益の時系列グラフ、表示範囲の指定、ズーム・移動・点の詳細表示。
- 月次履歴を日付降順で一覧・削除できる。
- 1人目の贈与収入は投資収入同様に、2人目の贈与支出は資産合計・損益へ反映する。
- 贈与の入力は、対応するもう一方のアカウントへ同額を同期する。

## 資産管理

- 月単位で、元本・実評価額・予測額・損益を確認・入力する。
- 1人目: 総合、投資信託、アクティブ、FXの資産管理と履歴。
- 2人目: 総合の手入力評価額と履歴のみ。投資信託の詳細管理、アクティブ、FXとは紐付けない。
- 投資信託・アクティブでは、投資信託と株式の保有数、価格、評価額、銘柄の追加・削除・編集を行う。
- 投資信託価格の手動/Yahoo参照、保有一覧、構成比を扱う。
- Googleスプレッドシート由来のMomentum候補・保有株情報を読み込み、アクティブ口座と同期する。
- 資産履歴を月・口座・入金・出金・元本・現在額・損益で確認・削除できる。

## FX（1人目のみ）

- 買い/売り、エントリー日・価格、Lot、スワップ、初期/追加保証金を入力する。
- USD/JPYの最新値を取得し、含み損益、必要証拠金、維持率、不足保証金、維持率100%レートを計算する。
- エントリー日から更新日までの含み損益/終値のグラフを表示する。
- 確定損益を日付ごとに記録・削除し、月別の履歴を確認する。

## 設定・周辺機能

- 投資信託、アクティブ、FXの想定年利を設定する。
- 月次予算を月ごとに編集し、その月のみ/以降の全月へ反映を選べる。
- PWAとして配布し、ログインゲートとキャッシュ更新を維持する。
- Momentum選定の独立ページで、対象銘柄、投資総額、保有株数、スプレッドシートの詳細情報を扱う。

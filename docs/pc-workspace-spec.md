# 現行UIの保守ルール

この文書は現在公開中のFinanceのUIを保守するための基準です。画面仕様を変更する場合は、先にこの文書を更新します。

## 構成

- 左レール: 資産、計画、設定、データ管理。
- 上部バー: 現在の画面名、金額表示の切替、K/M切替、同期状態。
- 資産: グラフを上、月別資産入力を下に配置する。
- 計画: 「予算」「その他」を縦に並べ、期間ごとは折りたたみ行として扱う。
- 設定: 年利を資産ごとに並べる。
- データ管理: バックアップ保存・復元を配置する。

## 表示上の原則

- 情報のまとまりは余白と罫線で区切り、意味のない入れ子カードは作らない。
- 入力欄と操作ボタンはラベルとの対応が分かる位置に置く。
- デスクトップを基準にしつつ、720px以下では上部タブと単列レイアウトへ切り替える。
- 金額・日付の編集、削除確認、キーボードでのタブ移動を維持する。

## 変更時の確認

- 既存のlocalStorage・Firestore・バックアップの形式を変更しない。
- 表示を変える変更では、資産・計画・設定・データ管理をPCとモバイルで確認する。
- 変更後は `npm run build` と `npm run pages:build` を実行する。

# PCワークスペース再設計仕様

## 情報設計

- 左レール: ホーム、資産管理、設定。最下部は保存状態。
- ヘッダー: アカウントの識別/切替、現在のページ名、保存状態。
- ホーム: 左に判断用のサマリーと切替式グラフ、右に月次実績入力。月次履歴は別表示にする。
- 資産管理: 総合、投資信託、アクティブ、FX、履歴を同じ作業領域内で切り替え、各作業面の幅を確保する。2人目は総合と履歴だけを表示する。
- 設定: 計算設定と月次予算を切り替える。月次予算は対象年を選び、12か月だけを一覧編集する。
- PCの外枠、ヘッダー、左レールは固定し、長い表や入力群だけを作業面内でスクロールする。

## 視覚規則

- PC専用。最小表示幅は1024px。
- 背景は淡い青灰、作業面は白、左レールは濃紺。
- 角丸: 作業面14px、入力とボタン9px、タブ7px。
- 通常の情報/操作文字は14px。見出しは15px以上、主要数値は28px。
- すべての通常入力・選択・金額入力は40px高に統一する。
- ティールは保存済み・主操作・安全な損益、赤は損失・注意だけに使う。
- ネストしたカードは原則使わず、同一作業面の内部は罫線と余白で区切る。

## 機能保持上のルール

- 保存形式・計算式・2人のアカウント分離・バックアップ形式を変更しない。
- 機能上の改善は、データ互換性または既存挙動を変える前に必ず承認を得る。
- グラフは現在月の前後を初期表示し、移動・拡大した表示範囲に合わせてY軸を自動調整する。手動範囲指定も維持する。
